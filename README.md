# 🎓 College Placement Prediction System

An AI/ML-based web application that predicts whether a student is likely to get placed based on academic performance, skills, internships, aptitude, projects, communication skills, backlogs, and certifications.

## 📌 Project Overview

The College Placement Prediction System uses Machine Learning to analyze student information and predict their placement status.

### Features

- Placement prediction
- Prediction confidence
- Personalized improvement suggestions
- Student performance analysis
- Professional PDF assessment report
- Model performance visualization

## 🎯 Problem Statement

Many students are unsure about their placement readiness.

This project provides an early assessment of placement readiness by analyzing important student factors and identifying areas that may need improvement.

## ✨ Key Features

### 👨‍🎓 Student Assessment

Students can enter:

- CGPA
- Technical Skills
- Internships
- Aptitude Score
- Projects
- Communication Skills
- Backlogs
- Certifications

### 🤖 Machine Learning Prediction

The system uses a **Random Forest Classifier** to predict placement status.

### 📊 Model Performance

- Training records: 500
- Test records: 100
- Test accuracy: 91%
- Algorithm: Random Forest Classifier

> Note: The dataset used in this project is synthetic. The reported 91% accuracy is based on the synthetic test dataset and should not be interpreted as real-world placement accuracy.

### 💡 Improvement Suggestions

The system provides suggestions based on the student's performance to help improve placement readiness.

### 📄 PDF Report

Students can download a professional placement assessment report containing:

- Student details
- Performance information
- Placement prediction
- Prediction confidence
- Improvement suggestions
- Model information
